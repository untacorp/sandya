# Security Policy

Sandya takes the security and privacy of disaster relief personnel, displaced persons, and emergency logistics data seriously.

Please see our comprehensive [Security Policy](.github/SECURITY.md) for:
- Supported versions & lifecycle
- How to privately report vulnerabilities via [GitHub Security Advisories](https://github.com/untacorp/sandya/security/advisories/new) or direct email
- Response timelines and SLAs
- Sandya threat model (Ed25519 cryptography, BLE mesh gossip, single-writer logistics, and START triage privacy)
- Safe Harbor protections for ethical security researchers
- Field guidelines for disaster response deployments and offline emergency patching
